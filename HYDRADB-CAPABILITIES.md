## Read this part first: the probes disagree with each other

The first probe reported almost the entire surface as unsupported.
Probes 2-6 then found the working syntax and overturned eight of its
verdicts. The corrections are listed rather than quietly dropped,
because the lesson is the useful part:

> An "unsupported" verdict from a probe is a statement about the
> probe until the alternative shapes have been tried.

probe1 wrote `CREATE (n:Label {props})` with no integer id and
concluded labelled CREATE was unsupported. The engine wanted a
one-hop edge pattern with an integer id on both ends. The engine was
fine; the query was wrong.
